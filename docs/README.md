# Документация проекта · Сравнительное исследование 3D-вращений

**Курсовой проект по дисциплине «Программная инженерия» · СКФУ, 2026**
**Траектория: «Исследование»**

Интерактивный исследовательский стенд для измеримого сравнения двух
математических моделей вращения 3D-объектов и двух вычислительных движков:

- **модели вращения:** кватернионы (axis-angle → quaternion) и матрицы поворота (Rx/Ry/Rz);
- **движки вычислений:** нативный **WASM** (Rust) и интерпретируемый **JavaScript**.

Стек: **Rust → WebAssembly → Vite → Three.js / WebGL**.
