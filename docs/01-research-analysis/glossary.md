# Глоссарий

Термины сгруппированы по темам. Расширенная версия исходного
`docs/глоссарий.md` (добавлены понятия исследовательской части и бенчмарка).

## 1. Математика вращений

### Кватернион (Quaternion)
Гиперкомплексное число `q = (w, x, y, z)`: `w` — скалярная часть, `(x, y, z)` —
векторная. Единичный кватернион кодирует вращение и используется для композиции,
интерполяции и устранения гимбал-лока.

### Ось-угол (Axis-Angle)
Представление вращения парой «единичная ось `(x, y, z)` + угол θ». Базовая форма
для построения кватерниона.

### Матрица вращения (Rotation Matrix)
Ортогональная матрица 3×3, задающая поворот. Базовые повороты вокруг осей — Rx,
Ry, Rz.

### Формула Родрига (Rodrigues’ rotation)
Способ повернуть вектор кватернионом без явного умножения:
`v' = v + 2·(q_w·(u×v) + u×(u×v))`. Используется в ядре проекта.

### Гимбал-лок (Gimbal lock)
Потеря одной степени свободы при совпадении осей в Эйлеровом представлении.
Кватернионы от него свободны.

### SLERP (Spherical Linear Interpolation)
Сферическая интерполяция между двумя кватернионами — гладкое вращение по
кратчайшей дуге.

### Композиция вращений
Объединение нескольких вращений: для кватернионов `q = q₁·q₂·…·qₙ`, для матриц
`v' = Rₙ·…·R₁·v`.

### Euler rotation (углы Эйлера)
Три угла (pitch, yaw, roll). В проекте напрямую не используются из-за гимбал-лока.

## 2. Векторная алгебра

### Вектор (Vec3)
Тройка компонент `(x, y, z)` — координаты, оси, направления.

### Нормализация вектора
Приведение к единичной длине: `v_norm = v / |v|`.

### Векторное произведение (Cross product)
Операция над двумя векторами, дающая перпендикулярный им вектор. Ключевая в
формуле Родрига.

## 3. Компьютерная графика

### Three.js
JavaScript-библиотека рендеринга поверх WebGL: сцены, камера, объекты. В проекте
отвечает только за визуализацию.

### WebGL
Браузерный API рендеринга 2D/3D-графики через GPU.

### BufferGeometry
Структура Three.js для хранения геометрии (массив позиций, индексы, нормали).

### Float32Array
Типизированный массив 32-битных вещественных чисел. Используется для передачи
вершин в WebGL и в линейную память WASM.

### LineSegments / wireframe
Отрисовка модели набором отрезков (рёбер) — каркасное представление.

### AxesHelper / ArrowHelper
Вспомогательные объекты Three.js: координатные оси (X-красный, Y-зелёный,
Z-синий) и стрелка-вектор (ось результирующего вращения).

## 4. WebAssembly и движки вычислений

### WebAssembly (WASM)
Бинарный формат исполнения в браузере, близкий по скорости к нативному. В проекте
скомпилирован из Rust.

### wasm-bindgen
Инструмент, генерирующий JS-обвязку для вызова Rust-функций из браузера и
маршалинга данных.

### Маршалинг (marshalling)
Копирование данных между JS и линейной памятью WASM. Накладной расход WASM-вызова,
влияющий на сравнение на малых данных.

### JS-fallback
Реализация тех же алгоритмов вращения на чистом JavaScript
(`src/math/rotations-js.js`) — для сравнения с WASM. Должна быть **алгоритмически
идентична** Rust-версии.

### JIT (Just-In-Time компиляция)
Динамическая компиляция «горячего» JS в машинный код движком (V8/SpiderMonkey).
Объясняет, почему оптимизированный JS может приближаться к WASM.

### SIMD
Single Instruction, Multiple Data — параллельная обработка нескольких значений
одной инструкцией. Потенциальный источник ускорения нативного кода.

### f32 / f64
32- и 64-битные форматы вещественных чисел. Rust-ядро считает в `f32`, JS — в
`f64` с усечением до `f32` при записи в `Float32Array`; отсюда расхождение
`~10⁻⁵…10⁻⁶`.

### Inplace-операция
Изменение данных без выделения нового массива — меньше памяти, ниже нагрузка на
сборщик мусора (GC).

## 5. Метрики и бенчмарк

### FPS (Frames Per Second)
Число кадров в секунду. В стенде сглаживается экспоненциальным средним.

### Время кадра / compute time
Длительность блока вычисления вращения за кадр (мс), замеряется
`performance.now()`. Основная метрика сравнения движков.

### Прогрев (warmup)
Холостые итерации перед замером (JIT-компиляция, прогрев кэшей), не учитываемые в
статистике.

### EMA (экспоненциальное скользящее среднее)
Сглаживание потока значений: `s ← α·x + (1−α)·s`. Используется для FPS и времени
кадра в оверлее.

### Бенчмарк-сессия
Автоматический прогон 300 кадров для каждого из 4 сочетаний {модель} × {движок} со
сбором min/max/avg времени кадра и проверкой корректности.

### Ускорение (speedup, ×)
Отношение среднего времени JS к среднему времени WASM для одной модели вращения.

## 6. Системные понятия проекта

### rmethod
Режим вращения стенда: `1` — кватернионы (axis-angle → quaternion), `2` —
матрицы Rx/Ry/Rz.

### engineMode
Активный движок вычислений: `'wasm'` или `'js'`.

### Нормализация модели
Центрирование и масштабирование модели к единичному размеру при загрузке.

### Pipeline рендеринга
Цепочка: загрузка модели → нормализация → вращение вершин → обновление
BufferGeometry → отрисовка на GPU.
