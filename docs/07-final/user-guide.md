# Руководство пользователя

## 1. Общая информация

Приложение — интерактивный исследовательский стенд для визуализации и **сравнения**
трёхмерных вращений. Реализовано на **Three.js** (рендеринг) с вычислениями на
**WebAssembly (Rust)** и эквивалентном **JavaScript-движке** (для сравнения
производительности).

Поддерживаются две модели вращения:

- **кватернионы** (ось-угол → кватернион → композиция);
- **матрицы поворота** Rx / Ry / Rz.

и два движка вычислений — **WASM** и **JS**, переключаемые на лету.

## 2. Назначение

- визуализация 3D-вращений в реальном времени;
- сравнение моделей вращения (кватернион vs матрица);
- **сравнение производительности WASM vs JavaScript** на одинаковой нагрузке;
- учебная демонстрация работы WebAssembly в компьютерной графике.

## 3. Интерфейс

### 3.1. 3D-сцена (слева)
- каркасная модель;
- оси координат: **X — красная**, **Y — зелёная**, **Z — синяя**;
- стрелка оси результирующего вращения (в режиме кватернионов);
- **оверлей метрик** поверх сцены: движок, FPS, время кадра (мс), число вершин.

### 3.2. Панель управления (справа)

| Элемент | Действие |
|---------|----------|
| **Движок: WASM/JS** | переключить вычислительный движок |
| **Модель** | выбрать `model.json` (легче) или `model.h.json` (детальнее) |
| «Через ось r» | добавить вращение кватернионом (ось + диапазон угла) |
| «Матрица поворота X или Y или Z» | добавить вращение матрицей Rx/Ry/Rz |
| «Очистить все» | удалить все вращения |
| **«▶ Запустить бенчмарк»** | замер 300 кадров × 4 сочетания |

## 4. Режимы вращения

### 4.1. Кватернионы (rmethod = 1)
Каждый узел задаёт ось `(i, j, k)` и диапазон угла `[мин; макс]`. Итоговое
вращение — произведение кватернионов всех узлов; применяется к модели через
ось-угол. Дополнительно показывается стрелка результирующей оси.

### 4.2. Матрицы (rmethod = 2)
Каждый узел задаёт ось матрицы (**Rx / Ry / Rz**) и диапазон угла. Вращения
применяются последовательно.

> При смене типа вращения предыдущие узлы автоматически очищаются.

## 5. Анимация

Каждый узел имеет флаг «Анимировать»: прогресс угла плавно идёт `0 → 1 → 0`
(эффект непрерывного покачивания). Ползунок «progress» позволяет задать положение
вручную.

## 6. Переключение движка и метрики

1. Запустите вращение.
2. Следите за строкой **«Кадр (compute)»** в оверлее — это время вычисления
   вращения за кадр.
3. Нажмите **«Движок»** для переключения WASM ↔ JS и сравните значение.

> Визуальный результат в обоих режимах **идентичен** — различается только время
> вычисления.

## 7. Бенчмарк-сессия

1. Выберите модель.
2. Нажмите **«▶ Запустить бенчмарк»**.
3. Дождитесь прогона (4 сочетания по 300 кадров; на детальной модели — несколько
   секунд).
4. Изучите таблицу: FPS, min/max/avg время кадра, коэффициент ускорения и
   проверку корректности.
5. Нажмите **«Копировать в буфер обмена»** — получите текстовый отчёт сессии для
   документации.

## 8. Управление камерой

- **ЛКМ + движение** — вращение сцены;
- **колесо мыши** — приближение/удаление;
- **ПКМ + движение** — перемещение (панорама).

## 9. Примечания

- стенд рассчитан на работу в реальном времени (≥ 60 FPS на лёгкой модели в WASM);
- точность вращения ограничена форматом `f32`; расхождение WASM и JS — на уровне
  округления `f32`;
- требуется браузер с поддержкой WebAssembly и WebGL.
