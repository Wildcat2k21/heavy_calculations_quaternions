# Техническая записка

> Обновлённая версия исходной `docs/техническая-записка.md`: добавлены движок
> JS-fallback, переключение движков, оверлей метрик и бенчмарк-сессия.

## 1. Общие сведения

Веб-приложение — исследовательский стенд для интерактивной визуализации и
**измеримого сравнения** трёхмерных вращений. Используются:

- **Three.js** — рендеринг (WebGL);
- **WebAssembly (Rust)** — вычислительное ядро вращений;
- **JavaScript-движок** — эквивалентная реализация ядра для сравнения.

Сравниваются две модели вращения (кватернион, матрицы Rx/Ry/Rz) и два движка
вычислений (WASM, JS).

## 2. Архитектура

Трёхслойная вычислительно-визуальная архитектура (подробно —
[03-architecture/system-architecture.md](../03-architecture/system-architecture.md)):

1. **Presentation** — Three.js, панель управления, оверлей метрик, бенчмарк;
2. **Math-JS** — композиция кватернионов, перевод в ось-угол, анимация,
   нормализация геометрии;
3. **Compute** — `rotate_vertices_axis_angle_inplace` и `rot_by_rotmat_inplace`
   в двух реализациях (WASM ↔ JS), переключаемых по `engineMode`.

## 3. Поток обработки данных

Загрузка JSON → нормализация → плоский `Float32Array` отрезков → покадровый цикл
(сброс к эталону → вращение выбранным движком → push на GPU → render). Подробно —
[03-architecture/data-flow.md](../03-architecture/data-flow.md).

## 4. Модели вращения

- **Кватернион (rmethod = 1):** `q_final = q₁·…·qₙ`, затем поворот вершин через
  формулу Родрига.
- **Матрица (rmethod = 2):** последовательные повороты `Rx/Ry/Rz`.

Формулы — [03-architecture/math-model.md](../03-architecture/math-model.md).

## 5. Оптимизация производительности

- **inplace-вычисления** — без аллокаций на кадр, низкая нагрузка на GC;
- **WebAssembly** — перенос «горячих» циклов в нативный код;
- **минимизация обновлений GPU** — `needsUpdate` только после изменения буфера;
- **эталон + рабочий буфер** — отсутствие накопления ошибки между кадрами.

## 6. Инструменты сравнения (новое)

- переключатель движка **WASM/JS** (единые диспетчеры `rotateQuat`/`rotateMat`);
- оверлей метрик реального времени (FPS, время кадра, число вершин);
- **бенчмарк-сессия**: 300 кадров × 4 сочетания, прогрев, статистика, проверка
  `max |WASM − JS|`, экспорт отчёта.

Методология — [05-benchmark/methodology.md](../05-benchmark/methodology.md).

## 7. Графическая подсистема

`Scene`, `PerspectiveCamera`, `WebGLRenderer`, `LineSegments` (каркас),
`AxesHelper`, `ArrowHelper`. Управление камерой — `OrbitControls`.

## 8. Используемые технологии

JavaScript (ES-модули), Three.js, WebAssembly (Rust, wasm-bindgen), Vite,
`Float32Array`, HTML/CSS.

## 9. Заключение

Стенд демонстрирует интеграцию WebAssembly и WebGL и, в отличие от готовых
библиотек, предоставляет **встроенный воспроизводимый инструмент сравнения**
движков и моделей вращения. Архитектура разделена на визуальный, координирующий и
вычислительный слои, что обеспечивает честность сравнения и расширяемость.
