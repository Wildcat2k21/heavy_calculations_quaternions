## Наблюдения

- **Отставание от WASM:** JS медленнее во всех режимах — на ~25–33 % (лёгкая
  модель) и до ~56 % (матрица на детальной модели).
- **Кватернион vs матрица:** как и в WASM, матрица дешевле кватерниона
  (на детальной модели 1.280 vs 1.460 мс, ~12 %).
- **Стабильность:** максимум кадра до 3 мс (против 2 мс у WASM) — заметнее
  «провалы», характерные для JIT/GC.
- **JIT:** благодаря оптимизации SpiderMonkey разрыв с нативным WASM остаётся
  умеренным — это сильная сторона современного движка JavaScript.

## Окружение замера

- Дата: 23.06.2026
- Браузер / UA: Firefox 149.0 (Gecko/20100101)
- ОС: Ubuntu Linux x86_64

> ⚠️ Firefox округляет `performance.now()` до 1 мс — отсюда `Min = 0` и
> целочисленные `Max`. Средние по 300 кадрам репрезентативны.
