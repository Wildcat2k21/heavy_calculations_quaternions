## Статус данных

> ✅ **Данные собраны** (23.06.2026, Firefox 149 / Ubuntu Linux) для двух моделей —
> `model.json` (50 970 верш.) и `model.h.json` (326 786 верш.).

## Главные итоги

- WASM **быстрее** JS во всех 4 сочетаниях: **×1.25–1.56** по среднему времени кадра.
- Матрица дешевле кватерниона на **12–30 %** (меньше операций на вершину).
- Результаты движков **идентичны**: `max |WASM − JS| ≈ 10⁻⁷` (предел `f32`).
- Сложность **линейна** по числу вершин (рост ×6.4 при росте вершин ×6.41).
- **Потенциал WASM:** запас до **+2.4 млн вершин** в бюджете 60 FPS на матрице
  (см. [wasm-potential.md](wasm-potential.md)).

Подробности и таблицы — в [comparison.md](comparison.md).

## Как пересобрать данные

1. `npm run dev`, открыть стенд, выбрать модель, нажать **«▶ Запустить бенчмарк»**.
2. **«Копировать в буфер обмена»** → отчёт `=== BENCHMARK SESSION ===`.
3. Обновить `DATA` в [`scripts/gen-charts.mjs`](../../scripts/gen-charts.mjs) и
   запустить `node scripts/gen-charts.mjs` для перестроения диаграмм.
