# Диаграммы бенчмарка

Диаграммы построены в формате **SVG** (без внешних зависимостей) скриптом
[`scripts/gen-charts.mjs`](../../../scripts/gen-charts.mjs) по данным
бенчмарк-сессий. Перегенерация: `node scripts/gen-charts.mjs`.

| Файл | Тип | Что показывает |
|------|-----|----------------|
| `frame-time-chart.svg` | столбчатая | среднее время кадра (мс), WASM vs JS по методам (детальная модель) |
| `fps-chart.svg` | столбчатая | средний FPS (`1000/avg`) по сочетаниям |
| `radar-chart.svg` | радарная | 5 критериев × 4 сочетания |
| `degradation-chart.svg` | линейная | время кадра vs число вершин (50k → 327k) |
| `wasm-potential.svg` | линейная | **потенциал WASM**: экстраполяция к крупным сценам + бюджеты 60/120 FPS |

## Радарная диаграмма — критерии

Оси (нормировано 0…1, выше — лучше; детальная модель):

- **Производительность** — средний FPS;
- **Точность** — все в пределах `f32` (`max |WASM−JS| ≈ 10⁻⁷`) ⇒ 1.0 для всех;
- **Масштабируемость** — близость роста к линейному / амортизация overhead;
- **Простота** — субъективно (JS проще в поставке, матрица проще кватерниона);
- **Стабильность** — обратно к разбросу времени кадра (у WASM max 2 мс, у JS 3 мс).

> Оси «Простота» и «Стабильность» частично качественные — см. оговорку в
> [../methodology.md](../methodology.md).

## График потенциала WASM

Ключевая диаграмма для демонстрации потенциала технологии: экстраполирует
удельную стоимость (нс/вершину) на сцены до 10 млн вершин и показывает, при каком
числе вершин каждое сочетание упирается в бюджет 60 FPS (16.67 мс). Разбор —
[../wasm-potential.md](../wasm-potential.md).
