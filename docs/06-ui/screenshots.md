## Элементы интерфейса

| Элемент | Назначение |
|---------|-----------|
| 3D-сцена (слева) | каркасная модель, оси координат (X-красн., Y-зел., Z-син.), стрелка оси вращения |
| **Оверлей метрик** (поверх сцены) | движок, FPS, время кадра (мс), число вершин |
| **Движок: WASM/JS** | переключение вычислительного движка |
| **Модель** | выбор `model.json` / `model.h.json` |
| «Через ось r» | добавить кватернионное вращение (ось + диапазон угла) |
| «Матрица поворота X/Y/Z» | добавить матричное вращение |
| «Очистить все» | сбросить все узлы вращения |
| **«▶ Запустить бенчмарк»** | прогон 300 кадров × 4 сочетания |
| Таблица результатов + отчёт | сводка и текстовый блок `=== BENCHMARK SESSION ===` |

> ⏳ После добавления новых элементов (переключатель движка, оверлей метрик,
> бенчмарк) рекомендуется обновить скриншоты `app1.png` / `app2.png`, чтобы они
> отражали актуальный интерфейс.
