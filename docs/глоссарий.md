# Глоссарий

## 1. Основные математические понятия

### Кватернион (Quaternion)
Математический объект, используемый для представления вращений в 3D-пространстве.

Форма записи:
\[
q = (w, x, y, z)
\]

- `w` — скалярная часть
- `x, y, z` — векторная часть

Используется для:
- плавной интерполяции вращений
- композиции нескольких вращений
- устранения проблемы гимбал-лока

---

### Ось-угол (Axis-Angle)
Способ задания вращения через:
- единичный вектор оси
- угол поворота вокруг этой оси

Формат:
- axis = (x, y, z)
- angle = θ

Используется как базовая форма для построения кватернионов.

---

### Матрица вращения (Rotation Matrix)
Квадратная матрица 3×3, описывающая поворот в пространстве.

Используется для:
- последовательных преобразований координат
- применения вращения к вершинам модели

---

## 2. Векторная алгебра

### Вектор (Vec3)
Объект, содержащий три компоненты:
- x
- y
- z

Используется для:
- описания координат
- задания осей вращения
- вычислений в 3D-пространстве

---

### Нормализация вектора
Процесс приведения вектора к единичной длине:

\[
v_{norm} = \frac{v}{|v|}
\]

---

### Векторное произведение
Операция двух векторов, результатом которой является новый вектор, перпендикулярный обоим исходным.

Используется в:
- вычислении вращений
- работе с осью-угол

---

## 3. Компьютерная графика

### Three.js
JavaScript-библиотека для работы с WebGL.

Используется для:
- создания 3D-сцен
- рендеринга объектов
- управления камерой

---

### WebGL
API для рендеринга 2D/3D графики в браузере через GPU.

---

### BufferGeometry
Структура данных Three.js для хранения геометрии:
- массив вершин
- индексы
- нормали

---

### Float32Array
Типизированный массив для хранения чисел с плавающей точкой (32-bit).

Используется для:
- передачи данных в WebGL
- взаимодействия с WebAssembly

---

## 4. WebAssembly и производительность

### WebAssembly (WASM)
Бинарный формат исполнения кода в браузере с высокой производительностью.

Используется для:
- ускорения математических операций
- обработки больших массивов данных

---

### Inplace операция
Операция, которая изменяет данные без создания нового массива.

Преимущества:
- меньше расход памяти
- выше производительность
- меньше нагрузка на GC

---

## 5. Вращения и трансформации

### rmethod
Режим системы вращений:

- `rmethod = 1` — кватернионы (axis-angle → quaternion)
- `rmethod = 2` — матричные вращения (Rx, Ry, Rz)

---

### Композиция вращений
Процесс последовательного объединения нескольких вращений:

\[
q = q_1 \cdot q_2 \cdot ... \cdot q_n
\]

---

### Euler rotation (не используется напрямую)
Способ задания вращений через три угла (pitch, yaw, roll).

Не используется в проекте из-за проблем гимбал-лока.

---

## 6. Графические сущности

### AxesHelper
Встроенный объект Three.js для отображения координатных осей:
- X — красный
- Y — зелёный
- Z — синий

---

### ArrowHelper
Объект Three.js для визуализации направленного вектора (стрелки).

Используется для:
- отображения оси вращения
- визуализации направления

---

## 7. Производственные термины

### Нормализация модели
Процесс приведения модели к:
- центру координат
- единому масштабу

---

### Pipeline рендеринга
Последовательность обработки:
1. загрузка модели
2. нормализация
3. применение трансформаций
4. передача в GPU
5. отрисовка сцены
